# reviews/ — 外部 AI 评审的收件匣

这个资料夹只放**评审意见**，不放程式。

## 规矩

1. **每一个评审开自己的资料夹**，用自己的名字：
   `reviews/FABLE5/`、`reviews/GPT/`、`reviews/GROK/`、`reviews/CLAUDE/` ⋯
2. **不准改这个资料夹以外的任何档案。** 不改 `src/`、不改 `docs/`、
   不改 `supabase/`、不改 `STATE.md`、不改 `CLAUDE.md`、不删任何东西。
   看到问题就写在自己的资料夹里，附上档名和行号。
3. **不准碰线上资料库。** 不跑 migration、不跑任何写入的 SQL。
4. 每一个资料夹里至少要有：

   | 档名 | 内容 |
   |---|---|
   | `01-评分.md` | 三个角度的分数 ＋ 一句话理由 |
   | `02-问题清单.md` | 找到的问题，一条一条，附 `档名:行号` |
   | `03-建议.md` | 建议怎么改，按「先做什么」排序 |
   | `04-我没能验证的.md` | 你查不到、只能用猜的部分。**这一份不可以省略** |

5. **讲得出「哪一个档案、哪一行、哪一个画面」才叫一条问题。**
   「使用者体验不好」不算一条；
   「`src/components/v2/sidebar.tsx:92` 用了 `truncate`，三语标签在 240px
   的侧栏会被切掉」才算。
