# 换模型手册

**写给以后的你。** 每次有新模型出来、或者哪一家涨价、或者你怀疑准确率掉了，
就翻这一份。**不需要改程式码。**

---

## 一句话版本

> 在 Vercel 改**一个环境变数**，重新部署，跑 `npm run eval` 看数字。
> 不满意就改回去。**五分钟，可回退。**

---

## 0. 先回答你问的：要不要先去弄 OpenAI 的 API？

**要，但不急，而且它不是第一优先。**

| 顺序 | 做什么 | 为什么这个顺序 |
|---|---|---|
| **1** | **Gemini 换成付费 key** | 这个**挡住上线**：免费层会拿你的输入去训练，所以一笔真实捐款人资料都不能进。花费 RM0.4–4.4/庙/月 |
| **2** | 跑一次 eval（真实手写），拿到基准数字 | 没有基准，之后所有比较都没有意义 |
| **3** | **再去开 OpenAI key** | 只是为了**比较**。luna 可能赢、也可能输 —— 见下面那个警告 |
| 4 | 按 eval 结果决定要不要换 | |

### ⚠ 一个我必须先讲清楚的事

OpenAI 自己的官方视觉文件写着：

> "**Non-English**: the model may not perform optimally when handling images
> with text of **non-Latin alphabets**, such as Japanese or Korean."

**Minit 读的是手写中文。** 所以 GPT-5.6 luna 虽然便宜（$0.20/$1.20），
**很可能在你最在乎的那件事上输给 Gemini**。

我把 OpenAI 接进来，**不是因为我认为它会赢，是因为你现在没有办法知道**。
跑完 eval 才知道。这正是那个 eval 存在的理由。

### 开 OpenAI key 的步骤

1. https://platform.openai.com → 注册 / 登入
2. **Billing → 先设 usage limit**（建议先设 US$5/月）—— 这一步不要跳
3. **API keys → Create new secret key**
4. 贴进 `.env.local`：`OPENAI_API_KEY=sk-proj-...`
5. Vercel → Settings → Environment Variables 也加一份

> **金钥只放这两个地方。** 不要贴进聊天、email、WhatsApp、云端笔记。
> 每一家都可以随时重新产生金钥，所以外泄了就去 revoke，不要犹豫。

## 1. 现在的架构（2026-08-03 起）

四种任务，**各自一个环境变数**：

| 环境变数 | 管什么 | 难度 | 换它的风险 |
|---|---|---|---|
| `AI_MODEL_CLASSIFY` | 「这张是会议记录还是捐款簿？」 | 三选一，**极简单** | **低** —— 小模型跟旗舰一样准 |
| `AI_MODEL_EXTRACT` | **读手写混语，抽成 JSON** | **最难** | **高 —— 准确率就是产品** |
| `AI_MODEL_CHAT` | 问答、意图分类 | 简单，纯文字 | 低 |
| `AI_MODEL_LONG_DOC` | 30 页章程 | 长，但不难 | 中 |

**格式**：`provider:model`，provider 是 `gemini` 或 `openai`。

```
AI_MODEL_CLASSIFY=openai:gpt-5-nano
AI_MODEL_EXTRACT=gemini:gemini-3.5-flash-lite
AI_MODEL_CHAT=openai:gpt-5-nano
AI_MODEL_LONG_DOC=gemini:gemini-3.5-flash-lite
```

**四个都不设也没关系** —— 会退回旧的 `AI_PROVIDER` / `GEMINI_MODEL`，
行为跟今天完全一样。这个分流层**预设是关的**，不会自己改变任何事。

## 2. 换模型：照这五步做

### 第 1 步 — 只改一个

**一次只动一个任务。** 同时换两个，出问题时你分不出是谁害的。

**从 `AI_MODEL_CLASSIFY` 开始** —— 风险最低，而且省最多（它占约 30% 的呼叫）。
`AI_MODEL_EXTRACT` 留到最后。

### 第 2 步 — 先在本机试

改 `C:\dev\minit\.env.local`，双击 `Buka Minit.bat`，
上传一张照片，看它有没有正常出结果。

**新模型最常见的失败不是「答错」，是「回不出合法 JSON」。**
如果画面显示「AI 读不懂这张」，多半就是这个 —— 换回去，别硬试。

### 第 3 步 — 跑 eval，看数字

```
npm run eval
```

**要看三个数字，缺一不可：**

| 看什么 | 合格线 |
|---|---|
| **OVERALL 准确率** | 不能比现在低。现在的基准是 **93.6%**（2026-07-18，打字排版案例） |
| **invented fields** | **必须是 0。** 不是 0 就直接淘汰，没有讨论空间 —— `CLAUDE.md` 规则 1 |
| **每次呼叫的成本** | 从 `ai_usage` 查（见第 3 节） |

> ⚠ **换成真实手写案例之后，基准数字会变**（多半会降）。
> 那时候要把「93.6%」换成新的基准再比。拿手写的分数跟打字的分数比是没有意义的。

### 第 4 步 — 上 Vercel

Vercel → 你的专案 → **Settings → Environment Variables** →
改那一个变数 → **Redeploy**。

### 第 5 步 — 一周后回头看帐

```sql
select model, count(*) as kali,
       round(avg(cost_micros)/1e6::numeric, 6) as purata_usd,
       round(sum(cost_micros)/1e6::numeric, 4) as jumlah_usd
  from ai_usage
 where model is not null
   and created_at > now() - interval '7 days'
 group by 1 order by 4 desc;
```

**估算跟实际一定有差距。** 以这个为准，不要以我文件里的估算为准。

## 3. 出事了怎么退回去

**改回原本那个环境变数，Redeploy。** 就这样。

没有资料库要回滚、没有 migration 要撤、没有程式码要 revert。
`ai_usage.model` 会记下每一列当时用的是哪一个模型，
所以**换过去和换回来的成本、以及出事的时间点，事后都查得到**。

这就是当初把它做成环境变数、而不是写死在程式码里的全部理由。

## 4. 加一个新的供应商（Anthropic、自架模型…）

比换模型麻烦一点，但也只是**一个新档案**：

1. 复制 `src/lib/ai/openai.ts` → `src/lib/ai/anthropic.ts`
2. 改三个地方：URL、请求的 JSON 形状、价目表
3. `provider.ts` 的 `resolveModel()` 里，`provider === "openai" || provider === "gemini"`
   加上 `"anthropic"`；`getVisionProvider()` 加一个分支
4. 然后 `AI_MODEL_EXTRACT=anthropic:claude-haiku-4-5`

**新档案必须照抄那四样东西**（不是可选的）：
timeout、429/503 退避重试、`maxOutputTokens`、`onUsage` 回报。
少任何一个，那家供应商就变成一个没有护栏的花钱漏洞。

## 5. 什么时候该回来看这一份

| 情况 | 做什么 |
|---|---|
| 有新模型发布 | **先看价格和它擅长什么，不要因为「新」就换。** 从 CLASSIFY 开始试 |
| 收到涨价通知 | 改那一个任务的环境变数。已知的：**Claude Sonnet 5 在 2026-09-01 涨 50%** |
| 模型要退役 | Google 的 Lite 系列换代很快（2.0 Flash 已经退役过一次）。退役公告一来就换，别拖到最后一天 |
| 帐单比预期高 | 先跑第 2 节第 5 步那个 SQL 看是**哪一个任务**，再决定动哪一个 |
| 准确率变差了 | 查 `ai_usage.model` 看是不是有人改过环境变数。然后跑 eval |

## 6. 比换模型更省钱的一件事（先做这个）

**上传前把照片缩小。**

手机拍的照片常常是 3000×4000。以 OpenAI 的算法，
`ceil(3000/32) × ceil(4000/32) = 94 × 125 = **11,750 个 patch**` 的输入 ——
而 GPT-5.6 在预设 detail 下**不会自动缩图**。

**读手写并不需要 4000px。** 长边缩到 1600px 通常就够，
输入 token 掉到大约六分之一，**每一家供应商都受惠，而且完全不影响准确率**
（这句话要用 eval 验证 —— 拿同一批案例，缩图前后各跑一次）。

这件事没做，换模型省的钱会被浪费的像素吃掉一大半。
`src/app/api/*/route.ts` 现在只有 `MAX_BYTES = 8MB` 一道门槛，
**没有任何缩图**。这是下一个该做的。
